# uvicorn[standard] rather than bare uvicorn: the [standard] extra is what
# pulls in a WebSocket implementation. Without it uvicorn rejects the upgrade
# on /ws/logs and the live pipeline tracker silently stops working — with no
# build-time error to catch it. `websockets` currently arrives transitively via
# langgraph-sdk/langsmith, but relying on someone else's transitive dependency
# for a load-bearing feature is how this breaks six months from now.
uvicorn[standard]
